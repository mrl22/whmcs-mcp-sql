## Explicit limits

This release is open/unauthenticated for development, with localhost HTTP publication by default. Secret fields/stores are blocked; embedded secrets in allowed business free text cannot be guaranteed absent. MyISAM reads do not offer a multi-table atomic snapshot. Long text and result sets are bounded. Live registrar reads and the absent Project Management addon schema are explicitly unavailable. MySQL 8.x is the supported database family; broader WHMCS/database/addon compatibility is not claimed. HTTPS proxies, private-CA database TLS and cloud-client account setup were documented but were not exercised against external production infrastructure.
